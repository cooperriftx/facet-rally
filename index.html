Don't lose your progress

Your coins, garage items, best times and custom tracks are only kept in this browser. Clearing browser data, private browsing or switching device will lose them.

  1. Open Save & load from the main menu.
  2. Tap Download save and keep the file somewhere safe, like Files or iCloud Drive.
  3. Next time, tap Upload save and pick that file to carry on.

No file? Tap Copy save code instead and paste it into a note. Use Paste save code to load it.
